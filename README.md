# TransformIA Coming Soon

Public coming-soon landing page for TransformIA.

## Scope
- This repository hosts the public coming-soon landing page for TransformIA.
- It does not contain private runtime code.
- Brand assets are sourced from `TransformIA-AI/Pngbrandassets`.
- Deployment target: Vercel.

## Local development
```bash
pnpm install
pnpm dev
pnpm build
pnpm preview
```
